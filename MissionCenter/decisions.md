# Decisions

- 首輪 3 個 issues：新航程未重設遭遇計數（有效，已修）；離開甲板可能遺留怪物（有效，已加 Server 端定期清理）；既有 `.codeblock` 換行變更（誤報，Git 顯示既有 codeblock 未修改，只有兩個新檔由 Maker 生成）。
- Maker 已驗證新航程計數歸零與離圖清理；斷線回收由相同的「找不到玩家」分支處理，但尚無實機斷線驗收。CodeRabbit 審查不取代大型地圖／UI 的結構及實機驗證。

## 2026-09-25：M1 遭遇與倒數規則（覆蓋舊版暫停規則）

- 每趟直航暫定固定 60 秒；空域決定遭遇牌組，但進入空域本身不強制抽牌。遭遇期間航程倒數**持續**，玩家可擊敗怪物，也可在船體尚可航行時撐到抵港；抵港時清除該趟未結事件與存活的甲板怪物。
- 60 秒僅是 M1 暫定值，後續再依原版航程節奏與船體／航線平衡調整。PC 為主要驗收平台；手機自動縮放不等於已通過觸控驗收。
- 2026-09-25 Maker 實測已確認森林→天空之城航程：菇菇出現後倒數繼續，未擊殺怪物仍於 60 秒抵港。尚未驗證四港所有往返、戰鬥擊殺結算及跨語言顯示，不能據此關閉整個 M1。
- 下方舊版兩港、三圖與 `SourceLanguage=ko` 紀錄為歷史決策／當時狀態；現行 M1 以四港、甲板及 `zh-tw` 原文設定為準。

## 2026-09-25：MSW 技能與多語言採用界線

- 沿用專案既有 `msw-*` 技能；官方 GitHub `msw-maker-base-skill` 與本地技能高度重疊，不重複安裝。素材先用 `msw-search` 找官方資源，無適用資源才繪製新圖；商店視覺可評估官方 UI 資源包，但既有金幣／貨艙交易不可直接換成付費商店套件。
- MSW 平台的自動翻譯是有條件的執行期功能，不是 Agent SKILL 自動翻遊戲。繁中為《空賊王》原文；關鍵港名、商品名與航程提示優先採經校對的 `LocaleDataSet`，其他文字才評估機器翻譯。先保持 PC 主驗收；UI 縮放不等於手機可讀性與點按自動合格。
- `WorldConfig.SourceLanguage` 目前為 `ko`，與繁中腳本文案不符。此值由 Maker 管理，須在 Maker 將原文語言設為繁中並重驗；不能把本次唯讀檢查說成已修復。

## 2026-07-08：採用方案 A

採用「最小資料/文字原型優先」。先不做甲板戰、航線 UI 或大巴正式戰，優先驗證貿易與航線風險循環。

## 2026-07-08：第一版核心邊界

- 單機，不做多人同步。
- 不做 PvP，不做玩家互搶。
- 不做真自由座標沙盒，第一版用自由直航與航線資料表。
- 玩家可從已解鎖地點直航到其他已解鎖地點。
- 空域是航線環境，不是可停靠地點。
- 地點才提供買賣、修船、升級、接任務。

## 2026-07-08：MVP 砍小

Phase 0 先做魔法森林與天空之城、普通雲海與黑雲帶、平安/寶箱/小怪/大巴前兆、船體與護盾升級。

## 2026-07-08：交易品分層

交易貨物用於買低賣高；升級素材用於船隻成長。避免玩家把關鍵素材全賣掉導致卡死。

## 2026-07-08：後續 Backlog

甲板戰、航線節點 UI、大巴正式反擊戰、海盜霧域、齒輪雲層、玩具城浮島、空賊鉤索與登船戰都排在 Phase 0 之後。

## 2026-07-09：第一版試玩採用按鍵文字循環

為了最快讓主人能在 Maker 內試玩，第一版先採用 @Logic 按鍵驅動文字流程：1 出航、2 升級船體、3 升級護盾、4 整備、R 重置。完整 HUD/UI、交易貨物買低賣高與 DataStorage 存檔延後，避免第一版被 UI builder、素材與資料持久化拖慢。

## B 階段：藏寶圖航線桌

固定方向：港口節點、航線與船隻棋子。先支援兩個港口，保留未來自由選航線與擴充港口的資料結構；第一版版面稍嫌空是可接受取捨，不擅自增加港口或其他玩法。
## 2026-07-14：核准 A+C 垂直切片與資料骨架

- 現在完成兩港口價差交易、style-4-blue UI、飛行視覺、甲板與三層船體、3 隻橘菇菇空降及玩家 Attack→Hit 護船。
- Port／Good／Route／EncounterPool 採資料驅動；新增內容不複製主循環。
- 交易貨物與升級素材分離，抵港依實際售價計算利潤；出航本身不保證獲利。
- 角色成長與技能書商店只保留商品類型與解鎖事件邊界。
- 高難航線玩家離船空戰列入 B-T1，本 Cycle 不實作。

## 2026-08-05：三場景探索與啟航流程

- 使用三個獨立可步行地圖：魔法森林港口 `104020110`、航行甲板 `200090000`、天空城港口 `200000111`；保留既有 `map01`，不以單圖換背景冒充跨圖。

- 玩家在港口自由移動；只有靠近自製船時才顯示「啟航」。點擊後開啟世界地圖，選擇目的地並確認出發，先切到航行甲板，再抵達目標港口。
- 商店以可走近交談的 NPC 啟動，採繁中航海商會式雙欄交易 UI；可借鑑楓之谷與航海遊戲資訊架構，但不直接照搬韓文 UI 模板。
