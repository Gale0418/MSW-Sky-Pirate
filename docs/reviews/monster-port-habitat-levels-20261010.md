# 港口怪物棲地與等級考據

查證日期：2026-10-10。範圍：13 個既有港口＋時間神殿。妖精學園、艾利涅與艾洛丁列為魔法森林來源子區，不新增港口。

## 數量與適用範圍

官方公開 mob 素材索引共 3,132 包；保留原本 632 個外觀候選，補入 10 個未收錄素材，共 642 個唯一素材包。此次逐筆研究 124 包：111 個既有航路候選、11 個原作反查補充（其中幽魂女巫原本已收錄）、2 個地面／海底參考。124 包內 92 包來源資料已核對、24 包仍有映射或變體疑義、8 包來源不足。

配置分類：76 包港口候選、15 包來源／ID 待查、37 包範圍外或事件素材、3 包地面／海底參考；其餘 511 包尚未逐筆考據，保留在圖鑑完整檔案中。素材包可能合併多個同名變體，數量不等於物種數。

原作等級不是本作戰力。現代 GMS、歷史版本、星力、鏡像世界、組隊任務與角色等級連動內容分開標示；未知或動態等級不填固定數字。資料欄 classic 表示查得的舊資料，不保證所有數字都是大改版前。擁有 fly 動作不代表原生飛行 AI。未修改遊戲出怪、賞金或怪物行為；目前五種怪物接線維持既有設定。

## 重要校正

- 緋紅天空碼頭是神木村的 **Leafre: Crimson Sky Dock（240080000）**，連接飛龍騎士副本；與緋紅之心要塞不同。飛翔鷹、飛翔鷲、三色翼龍、格瑞芬多、夢幻龍族七個素材歸此副本子區。[官方 MapleSEA v092 公告](https://www.maplesea.com/news_events/view/patch_notes_for_version_092/)、[碼頭地圖](https://maplestorywiki.net/w/Crimson_Sky_Dock)。
- Crimson Stirge 原作在 Crimsonheart Castle，移至範圍外。
- 玩具城分塔上、塔底／地球防衛、鐘塔地下、時空副本；補回邱布、妖魔系、維京系、幽魂女巫及幽靈海盜，不把飛碟全部混入玩具城上層。
- 水世界採魚群與原生水域生物；海怒斯留作海底定點參考，不列空中首領。尖鼻鯊魚航路首領是本作強化草案，非原作 BOSS。
- 葛雷博士 mob/8880202 是 Lv55 的 Dr. Zindelblarp 怪物素材，不能套用另一 ID 的 Lv180 OMNI-CLN。
- 7140000／7160000 是星力幽靈海盜，現行等級 118／119；舊普通版 83／87 僅保留版本對照，不當作此星力素材歷史等級。
