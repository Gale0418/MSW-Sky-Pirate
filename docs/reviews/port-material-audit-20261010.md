## 推薦階段消耗方向

- **T0–T1：**以可用木材、蝸牛殼、低價羽毛／毛球作少量基礎耗材；每級 1–2 種材料，避免早期被迫跑港。採買機率受現行每港隨機約 60% 貨架、最多 12 種限制，避免把單一貨品設成唯一解鎖條件。
- **T2：**開始跨港組合，建議每個改裝選 3–4 類：木材／船體補強 + 帆布／繩索 + 齒輪或金屬碎料；動力改裝再加燃料或 A 級能源。可用瑞恩瓦礫、玩具城齒輪、埃德爾斯坦晶片／A 核心、天空或水世界補強料建立路線差異。
- **T3–T4：**要求 3–5 類跨港材料，加入導航、魔法、冷卻／火力、時間裝置或 S 級能源；對應天空導航、緋紅碼頭能量、神木魔法／時間碎片、玩具城黑暗塔奇昂、埃德爾斯坦能源。把稀有材料作數量瓶頸，避免只靠金幣跳級。
- **T5：**現金造價可按目標設為 9,999,999,999 G，但應將 Boss 戰利品設成獨立硬門檻，建議至少 2 種不同首領來源、每種 1–3 件，另加多港高階能源／導航／魔法耗材。可選西格諾斯靈魂碎片、魚王靈魂碎片、史烏靈魂碎片、格瑞芬多之角等已核實項；須先完成實際 Boss 掉落／解鎖流程，商店商品欄與 `tradeTier=boss` 不代表已完成戰鬥解鎖。如此 9,999,999,999 G 是資金門檻，Boss 戰利品是玩法門檻，兩者不互相取代。

## 資料缺口與實作前需定案

1. **造船消耗尚不存在：**目前 `materialUse` 是用途候選標籤，沒有 recipe、數量、船級限制或解鎖條件；以上數量是規劃建議，尚非遊戲規則。
2. **部分港缺真正硬材料：**楓之島港只有蝸牛殼補強；納希沙漠與靈藥幻境偏補給／加工／船員用品。建議保留港口貿易用途，不為湊齊類別硬貼成船體、金屬或能源料。
3. **未核實項不可依賴：**目錄中待核實商品（如天空炎魔核心、玩具城拉圖斯／OMNI-CLN、神木部分 Boss／布料、水世界巨居蟹貝殼床）不納入上述配方候選；日後完成核實再替換。
4. **Boss 門檻仍需掉落規格：**目前可用商品候選不等於遊戲內 Boss 獎勵已接線。需要另定 Boss、掉落數量／率、是否綁定與解鎖順序；日本商品及退役配方不作替代。
5. **取得路徑未全通：**直接核對 `GreatVoyageVoyageData.mlua` 的 `GetPorts`：水世界（`aqua`）與埃德爾斯坦（`edelstein`）目前 `merchantName = ""`；兩地商品目錄已配置但商人入口待接。另現行貨架隨機抽樣，未保證所列每項同時出現。
6. **價格尺度：**現役材料 basePrice 約 1,000–700,000 G，遠低於 T5 現金造價 9,999,999,999 G。若把最終價格當單一造價，應明訂材料是額外門檻；若要材料消耗本身構成主要資金回收，需補充材料定價／數量和造船費的經濟假設。此金額超過 signed 32-bit 整數上限；本次未檢視錢包欄位及扣款運算。9,999,999,999 在 JavaScript Number 安全整數範圍內，但這不能證明 MSW mLua number 或下游 JSON/RPC 傳遞無損，實作前須以原生欄位與運行流程驗證貨幣儲存、同步、扣款和 UI 顯示。
