# 空戰遭遇與固定賞金串接

更新：2026-10-12。程式已接入；本機與 Maker Server 邏輯／Client 快照切片通過。完整航程與多怪畫面仍待驗。這是實作 checkpoint，並非整個 M3 或正式服驗收完成。

## 摘要（Summary）

怪物吸引力只看出航時的貨艙固定價值，現金不計入。採用人工分類的 132 種資料，129 種啟用、3 種保留待校準；巴達雷伊與泡泡魚同為 Lv.28 基準。魔法森林／維多利亞港共用空域，13 個分類空域與全空域池保留；開放海域只使用全空域池。時間神殿保留分類，尚無對應靠港地圖。

## 已完成（Completed）

- 遭遇每累積 100 距離檢查一次，不因跨空域重置；不足 100 的尾段按距離折算機率。船級限制可抽的最高等級，貨值、額外誘惑與既有誘餌／隱密／共鳴卡分通道調整頻率、數量及種類，卡槽效果計算一次。
- 完整混編隊伍依同屏上限上場，剩餘怪排隊。每隻獨立 HP、攻擊時計、飛行路徑與賞金，擊殺後只有排隊怪加入，其他怪不瞬移；沒有超時自動勝利。普通怪不隨玩家船級、貨值或火力加血。戰鬥事件依時間處理，每更新最多 128 個事件，剩餘下次處理。
- Server 唯一判定死亡與防重 claim，賞金先記本趟，抵港或沉船時透過既有 CAS 帳號快照結算。沉船保留現金與已擊殺賞金，貨物清空。錢包超過 2,147,483,647 G 的賞金存 bountyCredit，港口有空間再領；舊 schema 2 無此欄位仍能載入。
- 航行 UI 顯示主目標與全隊剩餘數、賞金；Client 用既有模型投影多怪，不向 Server 發送可指定獎勵的請求。離圖回收視覺。
