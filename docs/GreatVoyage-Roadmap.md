# Great Voyage Roadmap

## 願景

打造一段可探索港口、可選航線、可交易並能在甲板上護船的楓之谷風格空中航海冒險；每個新增內容都應以資料驅動、可回歸驗收、PC 與手機都能理解為前提。

## 發布準則

- 核心港口→啟航→航行→抵港→交易循環可重複完成。
- 所有保留地圖有正確的 TileMapMode／Body／foothold 契約，且 build/runtime 無未解決錯誤。
- 交易、HUD、世界地圖與甲板戰的主要狀態互相一致。
- 視覺品質由使用者在 Maker 中確認；手機實機觸控、安全區、字級與可讀性由使用者實機確認。
- 完成項目有 MissionCenter 任務與 smoke／使用者測試證據，不以歷史記憶代替紀錄。
