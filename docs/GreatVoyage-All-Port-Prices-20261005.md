# 全港口商品買賣價格表

整理日期：2026-10-05；來源為目前本地專案設定，未冒充公開伺服器即時價格。

價格單位G，每箱／每件各1單位。玩家買入＝向商人買；玩家賣出＝商人回收。商品只在產地出售，外港不出售該貨物。

- 11個圖鑑產地、184項商品；156項verified，28項未核實而禁止買賣。
- 目前只開放魔法森林、天空之城、玩具城、納希沙漠；四港共有82項設定，其中67項可交易。
- 每個港口工作階段從可交易商品中抽取min(12, ceil(可交易數×0.6))項貨架；因此森林12、天空12、玩具城9、納希8。商品未上架時不能買入，但已持有的合格貨物仍可依表賣出。
- 買入價固定為商品price；本港賣出=floor(price×0.8)，外港賣出=floor(price×需求倍率+0.5)，未設定需求倍率時用1。沒有動態行情、稅費或折扣計入此公式。
- 未開放產地表格的買入價為設定參考，現階段無法去該港購買；「同港回收參考」亦不是目前可執行的交易。未核實商品的基準價仍列出，但所有賣出欄為—。
- 同名商品保留不同ID，例如玩具城的兩筆「太空食品」價格與倍率不同；表格不合併。
