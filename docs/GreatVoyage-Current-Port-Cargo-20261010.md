- 17 種配方商品與 8 種日本商品停止供貨，退出現役圖鑑。

## 造船規劃邊界

目前加入的是實體素材用途與查詢目錄，尚未建立造船廠消耗流程或 T3～T5 船價。

- T2 改裝：木材、帆布與繩索、齒輪、機械零件；依用途區分船體、貨艙、炮台、船帆與動力。
- T3～T4：再加入導航、魔法、冷卻、時間及高階能源材料，保留跨港採買需求。
- T5 與特殊武裝：需另設 BOSS 戰利品取得與解鎖，黑暗天堂空戰屬後續戰鬥里程碑。本輪不把商店購買的 BOSS 商品直接視為已完成戰鬥解鎖。
- 食品、藥草、收藏品等保留貿易用途，不強行當成船體材料。

補入「可用木材」：MSW 原生資源 `13c56df3d15b402f88a5034445f86403`，原物品 ID 4030022。魔法森林供貨為本遊戲設定，並未宣稱原作掉落地點。

現役 160 項，其中已核實可供貨 140 項；25 項退役資料僅留供舊貨艙相容。
