# Phase 0 可試玩版設計

## 目標

在 MapleStory Worlds Maker 的 Play Test 中提供第一個可互動的純文字航行循環。玩家可以從魔法森林與天空之城之間出航，抽航行事件，結算金錢、素材、護盾與船體損傷，並進行船體或護盾升級。

## 非目標

- 不做完整 UI builder 介面。
- 不做自由座標航線或飛船物理。
- 不做甲板戰、怪物正式戰鬥或多人同步。
- 不做 DataStorage 永久存檔。

## 操作

- `1`：出航。
- `2`：升級船體。
- `3`：升級護盾。
- `4`：港口整備，修船並補護盾。
- `R`：重置原型資料。

## 核心資料

- 地點：魔法森林、天空之城。
- 空域：普通雲海、黑雲帶。
- 事件：順風、漂流寶箱、空賊小怪、大巴前兆。
- 成長：船體等級、護盾等級。
- 資源：金幣、雲海結晶、船體 HP、護盾耐久。

## 驗證方式

在 Maker Play Test 中連續按 `1` 出航至少 5 次，期間至少觸發 2 種不同事件，並完成至少 1 次升級或整備。Console log 需要能看到每次操作的狀態摘要；Build Console 不應出現編譯錯誤。
